Mathematical Derivation

Let P be the initial principal, A the fixed monthly payment, r the monthly interest rate, and n the number of monthly payments.

The present value of the repayments must equal the original principal:

P = A * (1/(1+r) + 1/(1+r)^2 + ... + 1/(1+r)^n)

Factor out A:

P = A * [1/(1+r) + 1/(1+r)^2 + ... + 1/(1+r)^n]

This is a finite geometric series with first term a = 1/(1+r) and common ratio q = 1/(1+r).

Using the finite geometric-series identity:

S_n = a * (1 - q^n) / (1 - q)

Substituting and simplifying gives:

P = A * (1 - (1+r)^-n) / r

Rearranging leads to the EMI formula:

A = P * (r * (1+r)^n) / ((1+r)^n - 1)

Where r = R / 1200 and n = 12 * T. If r = 0, then A = P / n.

Discounting future payments by powers of (1+r) converts them to present value, reflecting the time value of money.
